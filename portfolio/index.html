I design agentic systems: autonomous agents that plan over long horizons, remember across sessions, route work to the right specialist and recover when a tool fails at step 40. The model is only part of the job. Most of the work is in the harness around it: the loop, the memory, the guardrails and the evals.

The agentic
engineering toolkit

Everything between a single model call and an agent you can trust to run unattended.

Autonomous & long-horizon agents

Planning, tool-calling and step budgets for agents that work through long, multi-step tasks without drifting.

Agentic AI system design

Choosing between single loops, routers and multi-agent graphs, and keeping each as simple as the problem allows. LangGraph, OpenClaw.

Loop & harness engineering

Agent loops, context management, tool schemas and the harness that connects models to real systems.

Agentic memory

Short- and long-term memory with LLM extraction, summarization, compaction and semantic recall.

Advanced RAG

Retrieval beyond basic top-k search: query rewriting, re-ranking and grounding checks on Pinecone.

Guardrails & human-in-the-loop

Input and output validation, policy checks, approval gates and escalation to a human when confidence drops.

Durable execution & self-healing

Checkpointed, resumable runs with retries, repair and re-planning when tools or models fail.

AI agent routers

Routing each request to the right specialist agent or model, with confidence thresholds and fallbacks when a provider fails.

Agent sandboxes

Isolated environments for agent tool calls and code execution, scoped so an agent can act without putting real systems at risk.

MCP servers & tool integration

Connecting agents to tools and data through Model Context Protocol servers, with typed schemas and scoped permissions.

LLM fine-tuning

Fine-tuning open-weight models on domain data, and knowing when prompting or RAG is the better call.

Observability & evals

Opik and LangSmith tracing, evals with DeepEval, TruLens and Evidently AI, plus LLM-as-judge scoring and regression suites that gate every model or prompt change.
